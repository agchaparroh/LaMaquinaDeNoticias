Analiza las relaciones temporales entre hechos y detecta posibles contradicciones usando el contexto temporal del texto original.

# HECHOS PARA RELACIONAR
{{HECHOS_CONTEXTO}}

# TEXTO CON CONTEXTO TEMPORAL
{{TEXTO_SIMPLIFICADO}}

Identifica y establece las siguientes relaciones temporales:

## 1. RELACIONES HECHO-HECHO
- Identifica relaciones temporales y causales entre los hechos extraídos
- Tipos de relación: causa, consecuencia, contexto_historico, respuesta_a, aclaracion_de, version_alternativa, seguimiento_de
- Asigna fuerza de la relación (1-10)
- Incluye descripción de cómo se relacionan basándote en el contexto temporal del texto

## 2. CONTRADICCIONES
- Identifica si hay hechos que se contradicen entre sí
- Tipos de contradicción: fecha, contenido, entidades, ubicacion, valor, completa
- Asigna grado de contradicción (1-5)
- Proporciona descripción de la contradicción

DIRECTRICES IMPORTANTES:
- Usa el texto simplificado para identificar marcadores temporales ("después", "como consecuencia", "en respuesta a")
- Usa exactamente los IDs de hechos proporcionados
- Basa las relaciones temporales en el contexto explícito del texto
- Solo identifica contradicciones claras y evidentes
